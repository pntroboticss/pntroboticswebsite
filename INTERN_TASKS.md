# 🚀 Intern Assignments & Responsibilities

Welcome! As part of the engineering team at PNT Robotics, we divide our focus to ensure no one overwrites each other's code.

## Your Domain: Home Page & About Us
You are the primary maintainer for the following pages:
1. **Home Page (`src/app/page.tsx`)**
2. **About Us Page (`src/app/about/page.tsx`)**

### Your Current Tasks:
- Monitor the UI responsiveness of the Home and About pages on mobile devices.
- Refine animations, update photos, or change text on these pages as requested.
- **Do NOT** modify the Careers, Services, or Products pages without prior discussion, as the Senior Developer is actively working on those.

### Workflow Reminder:
When you start a task, always create a branch first:
`git checkout -b feature/your-task-name`

Once finished, push the branch and open a Pull Request (PR) on GitHub for review!

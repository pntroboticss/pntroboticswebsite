# PNT Robotics Website

A modern, responsive website built with Next.js App Router for PNT Robotics.

## Tech Stack
- Next.js (App Router)
- React
- Tailwind CSS
- Framer Motion
- React Three Fiber / Drei (for 3D elements)

## Getting Started

First, install the dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deployment

This website is configured for seamless deployment on [Vercel](https://vercel.com/) for testing. Production will be deployed on AWS.
